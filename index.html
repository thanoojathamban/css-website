CASCADING STYLE SHEET-CSS





CSS (Cascading Style Sheets) is a styling language used to design and make HTML webpages look beautiful and attractive. It helps us to add colours, backgrounds, fonts, images, borders, spacing, and animations to a webpage. With CSS, we can control the size, position, and layout of different elements such as headings, paragraphs, images, and buttons. It also helps us create responsive websites that look good on mobile phones, tablets, and computers. CSS makes a simple HTML webpage more colourful, organised, and user-friendly.



About CSS


CSS stands for Cascading Style Sheets,
CSS is used to style HTML web pages,
It controls colours, fonts and backgrounds,
CSS helps to create attractive website layouts,
It manages spacing using margin and padding,
CSS provides animations and hover effects,
CSS Flexbox and Grid help arrange elements,
CSS makes websites responsive on different devices,
CSS supports transitions and transformations,
CSS improves the overall appearance of websites.

CSS POSITIONS

The CSS position property is used to control where an HTML element appears on a webpage,
It helps us move boxes, images, headings,buttons and navigation bars to different positions.


CSS has 5 main position values:
